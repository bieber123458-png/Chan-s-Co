# 小陳的 30 天經營系統

結合 AI 個人成長教練、事業經營顧問、社群內容顧問、財務管家、存錢與負債管理的 30 天行動系統。

- 前端：React 19 + Vite（手機優先、響應式）
- 後端：Node.js + Express（同一個伺服器同時提供網站與 API）
- 資料庫：SQLite（Node.js 內建的 `node:sqlite`，不需額外安裝資料庫軟體）
- AI：Claude API（`@anthropic-ai/sdk`），**只在後端呼叫**，金鑰只放在環境變數

> 這個資料夾是獨立的 App，不會影響專案根目錄原本的 `index.html`（銷售網站）與 `booking.html`（預約表單）。

---

## 1. 如何啟動與預覽

需求：**Node.js 22.13 以上**（`node -v` 確認）。

```bash
cd app
npm install
cp .env.example .env      # 填入 ANTHROPIC_API_KEY（可先不填，AI 會顯示「尚未設定」）
npm run build             # 建置前端
npm start                 # 啟動 → 打開 http://localhost:8787
```

開發模式（修改程式碼會自動重新整理）：

```bash
npm run dev               # 前端 http://localhost:5173，API 自動轉到 8787
```

第一次打開會請你建立帳號（第一個帳號一定可以建立；之後預設關閉註冊，避免別人註冊後用掉你的 AI 額度。若要開放，在 `.env` 設 `ALLOW_REGISTRATION=true`）。

| 生活與成長 | 每日習慣（運動、喝水、睡眠、閱讀、情緒、飲食）、近 7 天表；日記新增／編輯／刪除＋AI 反思問題 |
| 積分與抽卡 | 完成任務得分（取消完成才會扣回，漏做不扣分）；每 30 分抽一次；64 張鼓勵卡（行動力、自信、療癒、事業成長各 16 張）；收藏圖鑑與抽卡歷史；不涉及金錢 |
| 每週／每月覆盤 | 自動統計任務完成率、內容產出、IG 表現、收支、儲蓄與還款、團隊變化；列出資料不足之處；系統依數字整理做得好的事／主要問題；每月目標與實際比較；AI 覆盤與建議 |
| 設定與備份 | 個人目標、緊急預備金月數；JSON 完整備份與還原（還原前確認）；11 種資料 CSV 匯出（含 BOM，Excel 開啟不亂碼） |

計算原則：

- **還款不重複計算**：收支紀錄不記還款；還款只記在「負債」，並拆成本金與利息，只有本金會減少剩餘債務。
- **可用餘額** = 收入 − 支出 − 本月還款 − 本月存入（存錢不算支出，但會從可用餘額扣除）。
- **營收 ≠ 利潤**：零售毛利 = 營收 − 成本；事業淨收入 = 收入 − 事業成本。
- 零售訂單是業績追蹤；實際入帳請在收支紀錄另記一筆收入（避免月收入重複或漏算）。

## 3. AI API 與資料庫設定

### AI（Claude API）

1. 到 <https://console.anthropic.com/> 建立 API 金鑰。
2. 在 `app/.env` 設定 `ANTHROPIC_API_KEY=你的金鑰`（部署時改在平台的環境變數設定）。
3. 重新啟動伺服器。左側「設定與備份」會顯示「AI 已設定」。

- 預設模型 `claude-opus-5-5`，可用 `AI_MODEL` 更換。
- 已開啟伺服器端備援（AI 拒答時自動改用建議模型）；若要關閉設 `AI_FALLBACKS=off`。
- 金鑰只存在後端環境變數，前端程式碼與瀏覽器拿不到。未設定時，所有 AI 按鈕停用並顯示「AI 尚未設定」，不會假裝有回覆。

### 資料庫

- 預設存在 `app/data/app.db`（SQLite，已排除在 Git 之外）。可用 `DATABASE_PATH` 指定位置。
- 資料表：`users`（帳號，密碼以 scrypt 雜湊）、`sessions`（登入憑證）、`records`（所有資料，依使用者與類型分開：任務、日記、財務、社群數據、抽卡、AI 分析歷史等）。
- **部署注意**：SQLite 是一個檔案，部署平台必須有「持久化磁碟」（例如 Render Disk、Railway Volume、Zeabur Volume、自己的 VPS），並把 `DATABASE_PATH` 指到該磁碟。Vercel／Netlify 這類 serverless 平台沒有持久化磁碟，不適合直接部署這個版本。
- 備份：定期在「設定與備份」下載 JSON，或直接複製 `app.db` 檔案。

### 部署

專案根目錄已附 `render.yaml`，可一鍵部署到 Render，步驟見 [DEPLOY.md](DEPLOY.md)。其他平台（Railway、Zeabur、VPS）設定：Build `cd app && npm ci && npm run build`、Start `cd app && npm start`、環境變數 `ANTHROPIC_API_KEY`、`DATABASE_PATH`（指到持久化磁碟）、`NODE_VERSION=22`。

### 在 claude.ai 打開（Claude 雲端模式，不需要伺服器與金鑰）

發布成 claude.ai 頁面時，系統自動改用 Claude 雲端：資料存在頁面資料庫裡只有本人看得到的私人區（跨裝置同步），AI 透過本人的 Claude 帳號回答（第一次使用會詢問是否允許，用量算在 Claude 方案內），備份透過平台的下載確認視窗。程式在 `src/lib/cloud.js`，提示詞與伺服器版共用 `src/lib/prompts.js`。

### GitHub 網頁版＋Cloudflare 後端（AI 與雲端同步）

`system/` 是 GitHub Pages 上的網頁版（<https://bieber123458-png.github.io/Chan-s-Co/system/>）。`worker/` 是給它用的 Cloudflare 後端（登入、雲端資料、AI），部署步驟見 [worker/DEPLOY.md](../worker/DEPLOY.md)。部署後在網頁版「設定與備份 → 連接 AI 主機」貼上後端網址即可。

### 沒有後端時（本機模式）

如果只把 `dist/` 當靜態網頁開啟（例如 GitHub Pages），系統會自動切換成**本機模式**：資料存在瀏覽器 localStorage，畫面會清楚提示。限制：AI 無法使用、資料只在該瀏覽器、清除瀏覽器資料就會消失、無法跨裝置同步。請定期匯出備份。

## 4. 仍是示意或尚未連接外部服務的部分

- **Instagram 未連接**：預設帳號 @chan1201_ 與「帳號定位」可在設定修改，AI 會參考；但所有社群數據仍需從 IG 後台手動輸入。系統不會假裝讀取 IG。未來若要連接，需申請 Meta 的 Instagram Graph API（需商業／創作者帳號與 Facebook 粉專），再新增合法的 OAuth 連接。
- **AI 需要你提供金鑰**：開發時沒有可用的金鑰，因此已驗證「請求確實送到 Claude API」與「金鑰錯誤／未設定時的提示」，但尚未用真實金鑰看過回覆內容。設定金鑰後請實際試一次。
- 沒有忘記密碼、Email 驗證或多人協作；目前適合一人（或少數信任的人）使用。
- 預設 30 天計畫是範本，不是你的實際紀錄；系統不含任何假資料。
- 「團隊人數」「零售訂單」等都需要手動記錄，沒有串接公司後台。

## 5. 如何測試新增、編輯、刪除、重新整理後資料是否保留

自動測試：

```bash
npm test     # 財務計算、計畫產生、積分、覆盤統計、API（註冊、存取、刪除、資料隔離、AI 未設定）
```

手動測試步驟：

1. `npm run build && npm start`，打開 <http://localhost:8787>，建立帳號 → 按「建立預設 30 天計畫」。
2. **任務**：勾選一個任務 → 積分 +15；展開填寫執行結果與心得 → 「儲存紀錄」。按 F5 重新整理，確認勾選與紀錄還在。
3. **編輯／刪除任務**：到「30 天計畫」，編輯任務名稱、移到後一天、刪除一個任務 → 重新整理確認。
4. **財務**：「存錢與負債 → 收支紀錄」新增一筆收入 30,000；「負債」新增信用卡（剩餘 60,000、年利率 15%、最低 2,000）→ 記錄還款 5,000，應顯示本金 4,250、利息 750、額外 3,000；「存錢」新增目標並存入 3,000。回到總覽：可用餘額應為 22,000。重新整理確認數字不變。
5. **刪除確認**：刪除一筆收支，會跳出含財務提醒的確認視窗；確定後數字重新計算。
6. **社群**：新增一篇內容與觀看數 → 「數據分析」會顯示資料不足提醒（少於 5 篇）。
7. **跨裝置**：用另一個瀏覽器（或手機連同一台伺服器）登入同一帳號，資料相同。
8. **備份**：下載 JSON 備份 → 刪掉幾筆資料 → 「從備份還原」→ 資料回來。
9. **AI**：設定金鑰並重啟後，在任務按「請 AI 給我建議」、在 AI 教練送出一段話；未設定時應看到「AI 尚未設定」提示。
